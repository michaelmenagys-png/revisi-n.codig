Proyecto de Gestion y Revision de Codigo

Descripcion del Proyecto

Este repositorio contiene la implementacion y el proceso de revision de codigo fuente mediante la metodologia de Pull Requests y control de versiones con Git y GitHub.

Tecnologias Utilizadas

  • Lenguaje: HTML5 / JavaScript / Documentacion tecnica
  • Control de versiones: Git y GitHub
  • Metodologia: Revision de codigo entre pares (Code Review)

Metricas de Calidad de Codigo

  • Total de lineas revisadas (L): 150
  • Total de defectos encontrados (D): 3
